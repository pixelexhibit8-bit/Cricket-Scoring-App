Official Interactive Navigation Flow & Screen Blueprint

1. Main App Navigation Architecture (4 Core Footers)
🏠 Home ScreenSearch & Hub
  • 1Brand Header with CricFlow Logo & instant player/match search
  • 2Clean canvas with fast 4-tab bottom navigation

  • 1Live Filter: Ongoing matches with auto-refresh

  • 1Batters Tab: Runs, Avg, Strike Rate, 50s, 100s

  • 2Performance Badges (Century, 5-Wkt haul)

  • 1Team 1 & 2 Names + Logo Picker (10 IPL Presets)

  • 3Wide, No Ball, Bye Extras & Bowler Change

4. Ground Modals & Overlays Reference
Modal Name Trigger Button Functionality
WicketPendingModal OUT button (Scorer Pad) Select dismissal type: Bowled, Caught, LBW, Stumped, Hit Wicket & assign fielder.
RunOutModal RUN OUT button Select who was dismissed (Striker / Non-Striker), completed runs & throwing fielder.
ExtrasModal EXTRAS button Record Wide, No-ball, Bye, Leg-bye or Penalty runs without breaking ball sequence.
BowlerChangeModal Over Completion (6 legal balls) Select new bowler from squad (blocks consecutive overs by same bowler).
SquadSelectorModal Pre-match Setup Select 11-15 players for both teams or add custom local ground players.
TeamLogoPickerModal Setup Screen Logo Tap Select from 10 Cloudinary HD IPL logos (CSK, MI, RCB, GT, SRH, KKR, etc.).
